## 🤔 这是个啥？

一个**纯静态、零依赖、打开就能玩**的学科闯关网页游戏。

它不讲题、不布置作业、不弹「再做一套」。它做的事只有一件：

> **把"答对"这件事，变成一场越来越盛大的庆典。**

主角是一只叫**多帕吉（ドパキチ）**的小猴子。你每敲一个答案，它就甩着胳膊跑过来，把你的答案搬进格子里；答对了，它鼓掌、蹦跳、翻跟头，身后的彩旗、探照灯、礼花、金币、彩带雨一层层解锁。

答错？没有红叉、没有扣血、没有 Game Over。它只会眨眨眼，把提示递到你面前。

**唯一的目标就是：让你想再来一局。**

## 🎮 双学科，一键换台

顶部有两颗小胶囊，点一下就能在两条完全不同的赛道上横跳：

```
┌─────────────────────────────────────┐
│  🔢 数学速算   │   📖 语文速练      │
└─────────────────────────────────────┘
```

连 Logo 彩带上的字都会跟着变（「速算」↔「语文」），细节控狂喜。

### 🔢 数学速算

- **58 个小学技能**，覆盖 1~6 年级全学段
- 从「10 的组成」「一位数加减」，一路打到**竖式多位数乘除、小数、分数约分通分、百分比与比例**
- 竖式支持**逐步填格**——每一步进位、退位、余数都能单独作答，错在哪一步一目了然
- 技能树呈**有向无环图**，按依赖关系逐级解锁
- 首次游玩有**实力诊断测试**，测完自动推荐下一个该练的技能

### 📖 语文速练

- **240 道精选题库**，1~6 年级每个年级 40 道
- 四条发展线并进：

| 赛道 | 内容 | 示例 |
| :--- | :--- | :--- |
| 🈶 **成语速记** | 典故成语填空 | 守株[ ? ]兔 → **待** |
| 🔊 **读音速辨** | 多音字、易错音 | 「时间」的「间」读 → **jiān** |
| ✏️ **错别字辨析** | 形近字、同音字 | 选出书写正确的一项 → **川流不息** |
| 📜 **名句填空** | 必背古诗文 | 沉舟侧畔千帆过，病树前头万木[ ? ] → **春** |

- 答对之后，题目下方会浮出**知识点释义**——玩着玩着就记住了
- 题库分年级、分类型，年级练习和综合闯关都能用

## 🧠 语文模式的设计难题：中文怎么"打"得爽？

做语文模式时遇到的第一个坎儿特别现实：

> **数学只要敲数字，语文要打汉字。**

而打汉字意味着：切输入法 → 打拼音 → 选字 → 确认。一套流程下来，**连击节奏直接断掉**，多巴胺就泄气了。

所以语文模式做了一件事：**彻底放弃打字**。

改成了**四选一快速点按**：

```
┌──────────────┬──────────────┐
│  Ⓐ  待       │  Ⓑ  侍       │
├──────────────┼──────────────┤
│  Ⓒ  代       │  Ⓓ  袋       │
└──────────────┴──────────────┘
```

- 触屏直接点，电脑可以按 `1/2/3/4` 或 `A/B/C/D`
- 一题一拍，节奏不断，**连击可以一直续下去**
- 小猴子依然会把你的选项搬运到空格里，答对依然欢呼

**结论：中文学科也能做成音游。** 🎯

## 🎴 出题系统：不会让你做到重题

刷题游戏最大的敌人是"又是这道"。

所以语文模式内置了一套**三级优先出题牌堆（ChineseDeck）**：

| 优先级 | 规则 |
| :---: | :--- |
| 🥇 | 你**从没见过**的题 |
| 🥈 | 本轮**还没用过**的题 |
| 🥉 | 实在没得选了，才重新洗牌 |

再加一层**跨会话记忆**：所有做过的题会记在本地（最多 500 道），**下次重新打开也不会再抽到**——直到 240 道全部刷完才会重新洗牌。

数学模式则用**题目签名去重**，同一局内不会撞题。

## ✨ 还有什么好玩的

### 🎵 声音是"算"出来的，不是"放"出来的

整个游戏**没有一个音频文件**。所有的背景音乐、鼓点、欢呼、金币声、连击变奏——
全部由 **Web Audio API 实时演算合成**。

这意味着：音乐能跟着你的手速**实时加速、变调、叠加声部**，而且整个项目体积小到可以塞进一张图里。

### 🏆 300+ 奖杯 & 47 种装扮

- **306 项成就奖杯**：连击达人、满分大师、连续打卡、还有几个藏起来的秘密成就 🕵️
- **47 种可解锁内容**：小猴子的服装配色、舞台地砖、打击特效、BGM 曲目、笔迹风格
- 每日打卡日历 + 每日随机任务，签到攒印章还有额外奖励

### 🔒 你的数据，只在你自己的设备里

- 纯静态，**没有任何后端服务器**
- 所有进度、错题本、奖杯、装扮，全部存在浏览器 `localStorage`
- **不上传、不采集、不追踪**，连个统计脚本都没有

### ♿ 该有的都有

- 支持「减少动态效果」偏好设置，晕动症友好
- 音量、静音、动画强度都可调
- 键盘全流程可操作，关键元素带 ARIA 标注

## 🛠️ 技术架构：一个"三无产品"

| | |
| :--- | :--- |
| **无依赖** | 零 npm 包、零框架、零构建步骤 |
| **无音频文件** | 全部 Web Audio API 实时合成 |
| **无后端** | 纯静态，扔哪都能跑 |

具体来说：

- **原生 ES Modules** 驱动，没有打包器，源码即产物
- **Canvas + SVG + CSS 动画** 三层混合渲染特效
- **骨骼式角色驱动**：小猴子的手臂、耳朵、表情各自独立运动，还能"抢"东西、"扔"东西
- **确定性帧时钟**：动画由统一时钟驱动，可复现、可测试
- 本地字体（`woff2`），不依赖任何 CDN

### 一些实现细节

- 竖式小数点的**基线对齐模型**经过重构，修掉了原作中"第二行小数点下沉压穿横线"的问题
- 语文模式的选项按钮会**动态复用 DOM 节点**，避免频繁重排
- 动画等待与补间使用**定时器驱动 + RAF 双轨**，即使标签页切到后台也不会卡死流程

## 🚀 本地运行

纯静态项目，**不需要编译、不需要安装依赖**。用任意静态服务器托管 `app/` 目录即可：

### 用 Python（推荐）

```bash
python3 -m http.server 8089 -d app
```

### 用 Node.js

```bash
npx serve app -l 8089
```

然后打开 <http://localhost:8089/> 就能玩。

> 💡 项目使用原生 ES Modules，**必须通过 HTTP 访问**。
> 直接双击 `file://` 打开会被浏览器的同源策略拦住。

因为它就是一个静态文件夹，**随便扔哪都行**：

| 平台 | 说明 |
| :--- | :--- |
| **Cloudflare Pages** | 推荐。构建命令留空，输出目录填 `app` |
